General Description

JSI Assistant tool includes LLM Advisor for Compliance along with Transparency and explainability.
This codebase implements a Retrieval-Augmented Generation (RAG) assistant focused on EU AI-related regulations. It segments the laws, builds embeddings, retrieves relevant articles, and generates answers while displaying both sources and the LLM response. (GitHub)

Architecture

High-level flow

  1. Ingestion & Parsing → Scrape official regulation sites, store per-regulation JSON, split into overlapping passages with metadata (regulation, chapter, article, passage no.). (GitHub)
  2. Embeddings & Storage → Create passage embeddings (BAAI/bge-small-en), normalize, store metadata in SQLite and vectors in LanceDB. (GitHub)
  3. Retrieval → Vector similarity search in LanceDB, then re-rank pairs [query, passage] with sentence-transformers/all-MiniLM-L6-v2; merge passages back to full articles. (GitHub)
  4. Application Layer → FastAPI/Uvicorn web app (public & testing variants) constructs a prompt with retrieved context and calls OpenAI (default GPT-3.5-Turbo); UI shows user query, retrieved articles, prompt, and LLM answer. (GitHub)

Component Definition

  • data/* — per-regulation folders with scrapers and JSON outputs (e.g., parsing_ai_act.py, ai_act.json). (GitHub)
  • embed_store_data.py — merges JSONs, computes embeddings (BAAI/bge-small-en), writes SQLite metadata and LanceDB vectors. (GitHub)
  • retrieving_articles.py — candidate retrieval via cosine similarity + re-ranking with all-MiniLM-L6-v2. (GitHub)
  • app_public.py / app_testing.py — FastAPI apps (default parameters vs. configurable testing). (GitHub)
  • api_script.py, Dockerfile, package_requirements.txt, lancedb_files/*, data/*/*.db — API helpers, containerization, dependencies, vector/SQL stores. (GitHub)

Top Features

  • Covers four cornerstone EU regulations: AI Act, Data Act, Data Governance Act, GDPR. (GitHub)
  • Retrieval with LanceDB + SQLite metadata separation for efficient search & rich display. (GitHub)
  • Re-ranking using all-MiniLM-L6-v2 for higher precision answers. (GitHub)
  • Two app modes: public (simple) and testing (configurable model, tokens, temperature, embedding/re-ranker). (GitHub)
  • Transparency UX: shows query, retrieved articles, constructed prompt, and model response. (GitHub)

How To Install

Requirements

  • Python 3.9+
  • OpenAI API key (required to generate model responses)
  • (Optional) Docker Desktop for containerized run (GitHub)

Software

  • Clone: git clone https://github.com/lrei/legal-AI (the upstream README shows a clone of the original fork; use this repo URL for JSI). (GitHub)
  • Install deps: pip install -r package_requirements.txt (GitHub)

Summary of installation steps

  • Preferred: create venv → install requirements → run batch or start Uvicorn.
  • Docker: build image → run container → open http://localhost:8001. (GitHub)

Detailed steps

Option A — Local (venv)

cd legal-AI
python -m venv .venv
# Activate (Windows): .venv\Scripts\activate
# Activate (Unix): source .venv/bin/activate
pip install -r package_requirements.txt
# Public app
cd app-public
python app_public.py
# then open http://localhost:8001

(As in repo, you can also use the provided run_app.bat after pointing it to your absolute path.) (GitHub)

Option B — Docker

cd legal-AI
docker build --no-cache -t legal-ai-app .
docker run -d -p 8001:8001 --name legal-ai-container legal-ai-app
# then open http://localhost:8001

(GitHub)

How To Use

  1. Open the UI at http://localhost:8001/.
  2. Enter your legal query and your OpenAI API key.
  3. Submit to see the retrieved legal articles, the constructed prompt, and the LLM response.
  4. (Testing app) Configure model, temperature, max tokens, and embedding/re-ranker models as needed. (GitHub)
